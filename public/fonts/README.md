# Quantum Dice typography

Instrument Sans is used for headings, controls, labels, numbers and charts. Lora
is used for narrative body text, matching https://quantum-dice.com/.

The WOFF2 assets were downloaded from the website's public font resources on
28 October 2026. Both families are distributed under the SIL Open Font License;
the corresponding license files are included in this folder. The browser loads
these assets locally, without a third-party font service.
